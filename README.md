## ⚙️ Instalação

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/seu-usuario/relogio-digital.git
```

### 2️⃣ Acesse a pasta

```bash
cd relogio-digital
```

### 3️⃣ Execute o projeto

```bash
xdg-open index.html
```

Ou simplesmente abra o arquivo `index.html` no navegador.
